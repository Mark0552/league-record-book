# 2 Many Chiefs Not Enough Indians - League Record Book

Live site: https://mark0552.github.io/league-record-book/

Mobile record book for our fantasy football league: standings, playoff odds,
career head-to-head, records, money, luck, trades, drafts, and hall of fame,
built from the Sleeper API, ESPN league history (2015-2019), and the league
record sheet. Updated weekly during the season.
