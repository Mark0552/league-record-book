                                    Verdict

                                    Every source is redraft — no dynasty values. FantasyCalc is computed for this league's exact settings (12-team, 1 QB, 0.5 PPR redraft) and its curve prices the rank sources: ROS Consensus = Dynasty Daddy's rest-of-season consensus rank (provider-default scoring), FantasyPros ECR = their half-PPR rest-of-season consensus. Sleeper VOR and ESPN VOR = rest-of-season projected points above a replacement-level starter (12-team lineups). The table is each team's net: value received minus value sent, per source; players no source lists count as 0.
